# z/OS Connect Customer API Contract

## Purpose

Define the API contract used by the modern integration layer to access
existing VRUT Bank customer capabilities through z/OS Connect.

The contract is intentionally limited to capabilities currently supported
by the existing COBOL programs.

CICS Boundary

The z/OS Connect integration requires a CICS transaction boundary.

The current CICS wrapper invokes VRCB0100 using CICS LINK.

The COMMAREA contract must contain the data required by the called COBOL
program, including both the customer record and operation result.

The current wrapper does not yet fully implement this contract and will
be corrected during the CICS interface implementation phase.
